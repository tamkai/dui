# DUI 台本 JSON（場面の型 8 種）

台本→検査→描画→声→mp4 を 1〜2 分で回すための決まり。毎回ゼロから構成しない。

## 全体
```json
{
  "title": "短い題（画面には出さなくてよい）",
  "decision": "この1本で決めてほしいこと（1つだけ）",
  "decider": "discord:<判断する人の author_id>",
  "scenes": [ { "type": "...", "say": "ナレーション", ... } ]
}
```
- 1 本 60 秒以内、標準 30 秒。判断は 1 つだけ。最後の場面は必ず `question`
- `say` は 1 場面 1〜2 文、1 文 40 字以内（声を発話ごとに作り、ASR で照合する単位になる）
- `say` の英字・略語は片仮名で書く（例: 「アスク・リレー」「ディーユーアイ・ボット」）。画面の `text`/`label` は英字でよい。TTS が英字を読み違え、作り直しでも直らない（2026-11-01 実測）
- `say` は 1 場面 8 字以上を目安にする。極端に短いと声の長さの予測が伸び、余計な言葉が入りやすい
- `steps` の絵文字は `icons`（steps と同じ数の配列）か、各要素を `{"text": "...", "icon": "📝"}` にする
- 台本に `"theme": {"accent": "#..."}` を書くと、その 1 本だけ色を変えられる（make_confirm.py が描く前にコントラストを検査する）
- `sec` は任意。省略時は `say` の文字数から見積もる（約 7 字/秒）

## 型
| type | 使う時 | 必須の項目 |
|---|---|---|
| `title` | 冒頭の題 | `text`（15 字以内） |
| `line` | 一言で言い切る | `text`（20 字以内） |
| `situation` | 今どうなっているか | `points`（1〜3 個、各 20 字以内） |
| `compare` | 2〜3 案の違い | `items`: [{`label`, `good`, `bad`}]（2〜3 個） |
| `number` | 数字 1 つで見せる | `value`, `unit`, `caption` |
| `steps` | 手順 | `steps`（2〜5 個、各 16 字以内）、任意で各 `icon` |
| `flow` | 流れ図 | `nodes`（2〜6 個）, `edges`: [[from, to]]（node の添字） |
| `question` | 選んでもらう（最後） | `choices`: [{`emoji`, `label`, `action`}]（2〜3 個） |

- `question.choices[].action` は押された時に実際にやること。曖昧な動詞（「対応する」等）にしない
- 選択肢の `emoji`/`label` は、投稿本文・リアクション（または将来のボタン）とそのまま一致させる
- 色は背景と文字・強調の組み合わせを描画前に検査する（同色で見えないボタン・透明な強調ノードの事故があった）

検査: `python3 scripts/check_script.py < script.json`（標準ライブラリのみ。エラーがあれば終了コード 1）
例: `references/example-script.json`
